## 💀 The Threat: AI Package Hallucination

AI coding assistants (Claude Code, Cursor, Copilot, ChatGPT) frequently hallucinate believable library names:

```typescript
// Hallucinated by AI agent:
import { formatRelativeDate } from 'date-fns-relative'; 
import { useTactileSpring } from 'react-smooth-springs';
```

Neither package exists on npm. **Here is how attackers exploit this:**

1. Attackers crawl public GitHub commits and PRs generated by AI coding agents.
2. They identify unresolved imports and 404 package names.
3. They register those exact names on **npm** and **PyPI** with malicious payloads (crypto stealers, reverse shells, telemetry exfiltration).
4. The next developer who runs `npm install` or builds the repo gets silently compromised.

`slop-deps` proactively inspects your codebase and cross-checks every single import against live registries **before you push code or merge PRs**.

## 🔍 What it Checks

| Status | Threat Level | Meaning |
| :--- | :--- | :--- |
| 🔴 **HALLUCINATED** | **CRITICAL** | Package **DOES NOT EXIST** on npm / PyPI. An attacker can register it anytime. |
| 🟡 **SUSPICIOUS** | **HIGH** | Package was created in the last 30 days with minimal releases. High risk of newly registered lure. |
| 🟡 **UNRESOLVED** | **WARN** | Python import does not match canonical PyPI distribution name. |
| 🟢 **VERIFIED** | **CLEAN** | Established package with legitimate release history. |

## 🚀 Key Features

* ⚡ **Zero Runtime Dependencies:** Built strictly on native Node.js 18+ APIs (`fetch`, `fs/promises`). No bloat, no 50-package dependency trees.
* 🌐 **Multi-Ecosystem:** Scans JavaScript, TypeScript, React (JSX/TSX), Python (`.py`), and manifests (`package.json`, `requirements.txt`).
* 🐍 **Smart Python Dist Mapping:** Maps top canonical Python import names (`yaml` → `PyYAML`, `cv2` → `opencv-python`, `PIL` → `Pillow`, `sklearn` → `scikit-learn`, etc.) to prevent false alarms.
* 🎯 **Smart Built-in Filtering:** Automatically ignores standard Node.js (`fs`, `path`, `crypto`) and Python (`os`, `sys`, `json`) built-in modules.
* 🚦 **Fail-Closed CI/CD Design:** Returns `exit 1` on critical hallucinations, `exit 2` on missing directories or network errors, and `exit 0` on clean verification.

## 🛠️ CLI Usage & Options

```bash
# Scan current directory
slop-deps

# Scan a specific folder
slop-deps --dir ./src

# Output raw JSON for custom tooling or reporting
slop-deps --json

# Fail if network verification is incomplete
slop-deps --strict

# Display help
slop-deps --help
```

## 🛡️ Add to GitHub Actions (CI Protection)

Block hallucinated imports in your pull requests automatically:

```yaml
name: Supply Chain Sentinel

on: [push, pull_request]

jobs:
  slop-check:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: '20'
      - name: Scan for Hallucinated Dependencies
        run: node path/to/slop-deps/bin/slop-deps.js
```
