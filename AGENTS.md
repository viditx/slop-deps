# Skill routing - always active

Before starting ANY substantive task - creating or editing documents,
spreadsheets, slides, PDFs, charts, diagrams, data analysis, code, web apps,
research, file conversion, or anything multi-step or file-producing - do this
first:
1. Read the skill index below (or `skills/INDEX.md`, rebuilt if stale).
2. If any skill matches the task - even loosely - open its SKILL.md and follow it.
3. If several match, pick the most specific one; chain skills when the task
   spans domains.
4. Proceed without skills only for greetings, small talk, and one-line factual
   answers.

Never ask me to invoke a skill manually. Never claim a skill doesn't exist
without actually checking first. A skill sitting unused in the folder is the
exact failure we are fixing.

- audit-slop-deps - Scans project source files, git repos, and manifests for AI-hallucinated or typosquatted dependencies before they reach your lockfile.
