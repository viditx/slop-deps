# Security policy

## Reporting a vulnerability

Please do not report security vulnerabilities in a public issue.

Email [viditx@users.noreply.github.com](mailto:viditx@users.noreply.github.com)
with:

- a short description of the vulnerability;
- the affected file, command, or version;
- reproduction steps or a minimal proof of concept; and
- the impact you believe it has.

You will receive an acknowledgement as soon as possible. Please allow time for
investigation and a fix before publicly disclosing the issue.

## Scope

Reports are especially valuable for vulnerabilities involving unsafe parsing,
unexpected code execution, registry requests, cache handling, or `--fix` mode.
Please avoid sending real credentials or private project data.
